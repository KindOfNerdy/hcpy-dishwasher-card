# Changelog

## 0.1.2
- Switch-off button next to the start button while no program runs
- Delayed start: minus and plus with a picker in the middle
- The chosen program also shows while the dishwasher is off
- `starter_icon`: own icon for the extra switch
- Durations no longer break over two lines; the delayed start has a label like the program drop-down

## 0.1.1
- Start a program from the card: program drop-down, delayed start and a start button while the dishwasher is ready
- Switch-on button while the dishwasher is off; a hint when the door is open or remote start is not allowed
- `start_options`: options switched on before every start and after choosing another program
- `starter_name`: the extra switch shows its entity name and icon, or the name set here
- How long the chosen program takes, shown while the dishwasher is ready
- An icon for each program phase
- A note when the dishwasher does not take an option (not every program allows every option)
- Row: icon grey at rest and without background, smaller state line, rounded-square button like the tiles around it; errors in the theme's error color
